# Git Beyond Commit

Beyond the commands. Understand the history.

## Sobre o projeto

Laboratório prático de Git e GitHub, desenvolvido
para compreender controle de versão, gerenciamento
de commits, branches e resolução de problemas reais.

## Metodologia

Estudar. Compreender. Praticar. Documentar. Compartilhar.

Projeto desenvolvido com apoio do ChatGPT como
ferramenta de aprendizagem, orientação e revisão técnica.
